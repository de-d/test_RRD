
# DeliveryApp

Простое Rails-приложение для расчета стоимости доставки грузов.

## Функциональность

- Форма для создания заявки на доставку
- Расчет расстояния между городами с помощью API (`distancematrix.ai`)
- Автоматический расчет стоимости доставки по заданной формуле
- Сохранение заявок в базу данных (PostgreSQL)
- Просмотр созданной заявки пользователем
- Админ-панель через ActiveAdmin с просмотром всех заявок

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your_username/delivery_app.git
cd delivery_app
```

### 2. Установите зависимости

```bash
bundle install
```

### 3. Настройте базу данных

```bash
rails db:create
rails db:migrate
```

### 4. Запустите сервер

```bash
rails server
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

## Алгоритм расчета стоимости

1. Если объем груза меньше **1 м³** → **1 рубль/км**
2. Если объем больше **1 м³**, но вес ≤ **10 кг** → **2 рубля/км**
3. Если объем больше **1 м³** и вес > **10 кг** → **3 рубля/км**

Объём рассчитывается как:
`длина × ширина × высота` (в см) → переводится в куб. метры (`/ 1_000_000`)
